# Research notebook

`experiments.ipynb` is a clean, optional experimental notebook focusing on the original UCI 327 numeric-feature baseline. It recreates the Decision Tree and Random Forest methodology from the uploaded v7.1 notebook, and includes an optional Keras extension.

The application in `app.py` is a separate model trained from the **UCI 967 URL-text dataset** through `scripts/train_model.py`. Do not copy the UCI 327 Random Forest accuracy into the UCI 967 model report.

Notebook data require internet access; notebooks are not run as part of app startup. The original file combined successive, partially outdated iterations; those were intentionally not copied verbatim into the clean public repository.
